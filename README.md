# Physical Cisco Switch Labs

Hands-on Cisco Catalyst 3750 switching labs covering device discovery, secure management, VLANs, trunking, spanning tree, and troubleshooting.

## Overview

This repository documents my hands-on networking labs using a physical Cisco Catalyst 3750 switch. The goal of these projects is to develop practical networking skills through device configuration, verification, and troubleshooting while documenting each lab's process and results.

## Lab Environment

The physical lab consists of a Cisco Catalyst 3750 switch, a Windows laptop, and a USB-to-RJ45 console cable used to access the switch CLI through PuTTY.
